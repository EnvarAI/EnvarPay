# Envar integration paths

For current Agent connectivity use
[EnvarConnect](https://github.com/EnvarAI/EnvarConnect) and the
[public Agent guide](https://envar.ai/guide/agents).
Current paid seller services use [Envar account-balance claims](envar-balance.md).

Older Python releases linked here for their discovery/payment-reporting
integration. Those historical APIs are not the current balance-claim flow.
See the [Python migration guide](legacy/python.md) and the
[fixed 0.1.0a11 integration document](https://github.com/EnvarAI/EnvarPay/blob/c44bf8a1a04698241c47b17bcb2e675e8331fa89/docs/envar.md).
