# Archived payment experiments

These documents and test evidence describe the earlier local wallet, external payment protocols, and testnet escrow experiments. They are retained for audit and historical context. The current Envar product uses free A2A services and Envar account-balance purchases; start with the repository [README](../../../README.md) and [balance gate guide](../../envar-balance.md).

Historical payment receipts are not Envar account-balance deposits. Do not replay their setup commands against a current Agent.
