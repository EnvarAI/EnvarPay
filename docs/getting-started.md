# EnvarPay getting started

The active package is the TypeScript A2A seller runtime. Start with the
[local free-service example](local-free-service.md), then read the
[Envar balance seller contract](envar-balance.md) if you need paid services.

If you arrived from the Python package on PyPI, use the
[legacy Python migration guide](legacy/python.md) and the
[fixed 0.1.0a11 quickstart](https://github.com/EnvarAI/EnvarPay/blob/c44bf8a1a04698241c47b17bcb2e675e8331fa89/docs/getting-started.md).
The npm seller is not an in-place replacement for a Python wallet.
